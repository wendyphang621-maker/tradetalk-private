# TradeTalk 外贸口语练习室

面向个人学习的26轮商务英语引导练习，包括耳机、手机、咖啡机、孟加拉采购和中东会议场景。

## 隐私与部署

请将本项目保存于 GitHub 私有仓库。上传代码不等于发布网站，请勿自动开启公开托管。

本项目没有服务器登录验证。若后续托管，需要在托管层增加可靠的身份验证，才能限制为本人访问。不要用前端密码框代替访问控制。

练习回答和录音只保留在当前页面；刷新会清空。语音识别可能由浏览器的在线服务处理，录音和朗读功能依赖设备与浏览器支持。

课程中的型号、价格及商务条件仅供练习，不是实际报价。建议是关键词规则和参考句，不是自由对话 AI 或专业发音评分。
